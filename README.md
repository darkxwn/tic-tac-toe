# ⭕❌ Infinity Tic-Tac-Toe (Крестики-нолики с исчезающим ходом)

Кроссплатформенная игра в крестики-нолики с механикой исчезающего хода (максимум 3 фигуры на игрока), устраняющей ничьи и добавляющей глубину планирования.

## 🚀 Основные возможности
* **Уникальная механика:** максимум 3 активных хода на игрока; 4-й ход удаляет 1-й (FIFO).
* **Визуальный отклик:** фигуры плавно меняют прозрачность в зависимости от давности (100% -> 65% -> 35% с предупреждающей пульсацией перед исчезновением).
* **Одиночная игра:** 3 уровня сложности бота (Новичок, Тактик, Minimax-Гроссмейстер) — 100% оффлайн на устройстве.
* **Локальный мультиплеер (Hotseat):** игра вдвоем на одном экране без интернета.
* **Онлайн-мультиплеер:** игра по 4-значным кодам комнат через WebSocket-ретранслятор, с возможностью реванша в той же комнате без пересоздания кода.
* **Кроссплатформенность:** единая кодовая база (React 19 + TypeScript + Vite + Tailwind CSS), упаковываемая в:
  * **Веб** (браузер / PWA)
  * **Мобильные** (Android APK через Capacitor с виброоткликом Haptics)
  * **Десктоп** (Windows .exe через Tauri v2)

## 📁 Структура проекта
* `client/` — клиентское веб/мобильное/десктопное приложение.
* `server/` — легковесный WebSocket Relay сервер для онлайн-комнат.
